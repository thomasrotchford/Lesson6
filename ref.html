HTML Tag Quick Reference

Common tags, what they do, and how to write them

Head

Tag Purpose Attributes Example
<head> Holds page metadata none <head>...</head>
<title> Browser tab titel none <title>My Page</title>
<meta> Page metadata charset, name, content <meta charset="UTF-8">
<link> Conects resources rel, href <link rel="stylesheet" href="styles.css">

Sectioning

Tag Purpose Attributes Example
<header> Introductry content class, id <header>Welcome</header>
<nav> Navigation links aria-label <nav>...</nav>
<main> Main page content id <main>...</main>
<section> Themed content group id <section>...</section>
<article> Self-contianed content class <article>...</article>
<footer> Footer content class <footer>Credits</footer>

Grouping

Tag Purpose Attributes Example
<div> Generic contianer class, id <div class="card">...</div>
<p> Paragraph class <p>Hello!</p>
<ul> Unordered list class <ul><li>Item</li></ul>
<li> List item value (ordered lists) <li>Item</li>

Text

Tag Purpose Attributes Example
<h1> Top-level heading id <h1>Title</h1>
<a> Link href, target <a href="index.html">Home</a>
<strong> Strong importence none <strong>Important</strong>
<em> Emphasis none <em>Note</em>
<code> Code fragment none <code>color: blue;</code>

Tables

Tag Purpose Attributes Example
<table> Table contaner class <table>...</table>
<tr> Table row none <tr>...</tr>
<th> Header cell scope, colspan <th scope="col">Name</th>
<td> Data cell colspan, rowspan <td>Ada</td>

Forms

Tag Purpose Attributes Example
<form> Form container action, method <form method="get">...</form>
<label> Field label for <label for="name">Name</label>
<input> Single-line feild id, name, type, required <input id="name" name="name">
<textarea> Multi-line field id, name, rows <textarea rows="3"></textarea>
<button> Clickable button type <button type="submit">Send</button>

Global Attributes

These attributes work on most HTML elements.

Attribute Purpose Example
id Unique element identifer <p id="intro">Hello</p>
class Reusable style or script hook <p class="note">Hello</p>
lang Language of the content <p lang="en">Hello</p>
title Extra information <abbr title="Cascading Style Sheets">CSS</abbr>
hidden Hides an element <p hidden>Not shown</p>
