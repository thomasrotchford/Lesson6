CSS Box Model

Each element has content, padding, border, and margin

Property Purpose Example
box-sizing Controls how total width and height are calcuated box-sizing: border-box;
width / height Sets an element’s size width: 250px; height: 100px;
margin Space outside the bordr margin: 16px;
border Line around the padding and content border: 1px solid black;
padding Space inside the border padding: 12px;
position Sets positioning behavior position: relative;
top / left Ofsets a positioned element top: 10px; left: 5px;

Common positioning values

static (default), relative (offset from normal position), absolute (positioned relative to its containing block), fixed (relative to the viewport), and sticky (sticks while scrolling).

Example

.box {
   box-sizing: border-box;
   width: 250px;
   padding: 12px;
   border: 1px solid black;
   margin: 16px;
 }
