CSS At-Rules

At-rules begin with @ and controll how CSS is used.

@media

Applies CSS under a condition such as printing a page.

@media print {
  body { color: black; }
}

@supports

Applies CSS if the browser suports a feature.

@supports (display: grid) {
  .grid { display: grid; }
}

@import

Loads another stylesheet. Place imports before other ruls.

@import url("theme.css");

@font-face

Defines a font from a font file.

@font-face {
  font-family: "Example";
  src: url("example.woff2") format("woff2");
}

File names in the @import and @font-face examples are placeholders.
